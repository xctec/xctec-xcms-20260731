# Glossary

> XCMS 术语表

| 术语 | 说明 |
|------|------|
| 中台 | 本设计中指集团技术中台（即 XCMS），为各产线提供基础能力和共享服务 |
| 租户 | 中台中的独立业务实体，可以是集团、子公司、产线、项目或外部合作方 |
| 级联租户 | 树状层级租户体系，上级租户管理下级租户 |
| 管理面 | 面向管理员的管控界面，负责租户/用户/权限/配置等管理 |
| 业务面 | 面向普通用户的业务界面，负责流程/消息/文件等日常操作 |
| 管理可见 | 管理员默认可查看下级租户的元数据、配置、用量等信息 |
| 业务可见 | 需要特殊授权才能查看租户的业务数据（订单、客户等明细） |
| 业务可见授权 | 管理面发起的临时授权，允许管理员查看指定租户的业务数据 |
| 共享部署 | 多个租户共享同一个 XCMS 应用实例和数据库 |
| 独立部署 | 单个子公司独立部署 XCMS 应用实例和数据库 |
| Tier 1/2/3 | 业务面数据隔离分级：共享库/独立库/独立部署 |
| RBAC | 基于角色的访问控制 |
| ABAC | 基于属性的访问控制 |
| BPM | 业务流程管理 |
| SSO | 单点登录 |
