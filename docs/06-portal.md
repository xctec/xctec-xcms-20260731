# XCMS Portal

## 6. XCMS 门户设计

### 6.1 统一入口与导航

#### 6.1.1 功能概述

门户是 XCMS 的统一入口，根据用户角色和权限展示不同的界面：管理员看到管理面，普通用户看到业务面。

#### 6.1.2 门户路由

```
用户登录
    │
    ├── 管理角色 → 管理面门户（/admin）
    │   ├── 集团管理员 → 集团运营平台
    │   ├── 子公司管理员 → 子公司管理后台
    │   └── 产线管理员 → 产线管理后台
    │
    ├── 业务角色 → 业务面门户（/portal）
    │   └── 工作台 + 流程中心 + 消息 + 文件
    │
    └── 双重角色 → 顶部切换按钮
        └── 管理面 ↔ 业务面 一键切换
```

#### 6.1.3 导航结构

**管理面导航**：

```
管理面
├── 总览看板
├── 租户管理
├── 组织架构
├── 用户管理
├── 身份认证
├── 权限管理
│   ├── 角色管理
│   ├── 数据权限
│   ├── 权限策略
│   ├── 业务可见授权
│   └── 权限审计
├── 流程管理
│   ├── 流程模板
│   ├── 流程设计器
│   ├── 流程监控
│   └── 流程统计
├── 配置管理
├── 消息管理
├── 文件管理
├── 任务调度
├── 审计中心
└── 运营管理
```

**业务面导航**：

```
业务面
├── 工作台
├── 流程中心
│   ├── 发起流程
│   ├── 待办任务

│   ├── 我的申请
│   └── 流程查询
├── 消息中心
├── 文件管理
├── 个人中心
└── 开发者门户（预留）
```

### 6.2 工作台

#### 6.2.1 功能概述

工作台是业务面用户的首页，聚合待办、通知、数据概览、快捷入口，支持个性化定制。

#### 6.2.2 工作台组件

```
┌─────────────────────────────────────────────────────┐
│  工作台                                              │
├──────────────────────────┬──────────────────────────┤
│  待办事项（含跨租户）       │  通知公告                 │
│  ┌─────────────────────┐ │  ┌────────────────────┐ │
│  │☐ 采购审批 #001 [跨]  │ │  │ 系统维护通知        │ │
│  │☐ 请假申请 #042       │ │  │ 新流程模板上线      │ │
│  │☐ 合同审批 #008 [跨]  │ │  │ 配额调整公告        │ │
│  └─────────────────────┘ │  └────────────────────┘ │
├──────────────────────────┼──────────────────────────┤
│  我的申请                  │  数据概览                 │
│  ┌─────────────────────┐ │  ┌────────────────────┐ │
│  │ 报销 #001 审批中     │ │  │ 本月发起流程: 12    │ │
│  │ 采购 #002 已完成     │ │  │ 待办任务: 3         │ │
│  └─────────────────────┘ │  │ 跨租户任务: 2        │ │
│                          │  │ 存储使用: 2.3GB     │ │
├──────────────────────────┴─└────────────────────┘──┤
│  快捷入口（可自定义）                                  │
│  [发起流程] [我的文件] [消息中心] [个人设置]           │
└─────────────────────────────────────────────────────┘
```

- **待办事项**：显示当前用户的待办任务，跨租户任务有标记
- **我的申请**：显示用户发起的流程及状态
- **通知公告**：系统通知和租户内公告
- **数据概览**：个人相关的数据摘要
- **快捷入口**：可自定义的常用功能入口

#### 6.3.2 预留功能

```
开发者门户

├── API文档           接口文档、SDK下载

├── 调用统计          应用API调用统计
```
