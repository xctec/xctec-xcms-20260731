### # XCMS Product Overview

> Version: v1.0 | Date: 2026-07-24 | Status: Requirements Planning

## 1. 产品概述


### 1.1 背景与目标

集团业务复杂，产线众多，各产线各有特点。当前各产线在技术基础设施上存在重复建设、数据孤岛、能力分散、交付效率低等问题。

**XCMS 定位**：XCMS 作为各产线的技术底座，为全集团提供统一的、可复用的基础能力和共享服务。

**核心目标**：

| 目标 | 说明 |
|------|------|
| 统一底座 | 提供租户、组织、身份、权限、流程等基础能力，避免各产线重复建设 |
| 聚集业务 | 承载全集团业务，支持大规模租户接入，也能为单独子公司提供独立服务 |
| 数据管控 | 复杂的数据权限体系，保障数据安全与合规 |
| 能力共享 | 流程、消息、文件、配置等共享服务，降低产线接入成本 |
| 弹性部署 | 支持共享部署和独立部署两种模式，适应不同子公司需求 |


### 1.2 业务定位与价值

```
┌─────────────────────────────────────────────────┐
│                      XCMS                          │
│                                                  │
│   ┌─────────┐  ┌─────────┐  ┌─────────┐        │
│   │ 产线 A  │  │ 产线 B  │  │ 产线 C  │  ...   │
│   │ (租户)  │  │ (租户)  │  │ (租户)  │        │
│   └────┬────┘  └────┬────┘  └────┬────┘        │
│        │            │            │               │
│   ┌────┴────────────┴────────────┴────┐        │
│   │          XCMS 共享能力              │        │
│   │  租户·组织·身份·权限·流程·消息·文件  │        │
│   └───────────────────────────────────┘        │
│                                                  │
│   部署模式：                                       │
│   ├── 共享部署：多数租户共享一个 XCMS 实例             │
│   └── 独立部署：大型/特殊子公司独立部署 XCMS        │
└─────────────────────────────────────────────────┘
```

**价值体现**：

1. **降本**：基础能力建设一次，各产线复用，避免重复造轮子
2. **提效**：产线接入 XCMS 即获得全套基础能力，加速业务交付
3. **管控**：统一权限、统一审计、统一流程，集团可全局管控
4. **灵活**：大小租户分级隔离，独立部署支持特殊需求


### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| **多租户优先** | 所有能力从设计之初就支持多租户，租户隔离是第一公民 |
| **管理面与业务面分离** | 管理面负责管控，业务面负责使用，逻辑分离，权责清晰 |
| **共享优先，独立兜底** | 默认共享部署降低成本，独立部署满足特殊需求 |
| **逻辑隔离起步，物理隔离按需** | 单库 + tenant_id 起步，预留数据源路由，按需演进 |
| **模块化设计，可拆分** | 单体多模块，模块边界清晰，未来可按需拆分为微服务 |
| **数据库无关** | 基于 JPA 抽象，设计上支持任意关系型数据库 |
| **预留扩展，不过度设计** | 核心能力先实现，扩展点预留接口，不过度设计 |
