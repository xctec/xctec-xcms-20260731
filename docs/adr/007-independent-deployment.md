# ADR-007: 独立部署不互通业务数据

- **Status**: Accepted
- **Date**: 2026-07-24

## Context

XCMS 需要支持子公司独立部署。独立部署后，子公司与集团中台之间的数据关系需要明确：

- 业务数据是否互通？
- 流程是否互通？
- 身份认证是否互通？
- 元数据是否同步？

## Decision

独立部署的子公司与集团 XCMS **不互通业务数据**。只做元数据层面的注册与上报。

### 互通的内容

| 互通 | 说明 |
|------|------|
| 租户基本信息 | 独立部署租户在集团管理面注册 |
| 组织架构（可选） | 可选择上报组织架构摘要 |
| 资源用量 | 定时上报资源使用情况 |

### 不互通的内容

| 不互通 | 说明 |
|--------|------|
| 业务数据 | 订单、客户等完全不共享 |
| 用户明细 | 用户信息不同步 |
| 流程实例 | 流程不互通（独立引擎） |
| 消息数据 | 消息不共享 |

### 预留扩展

未来如需业务互通，通过标准化 API 对接，不在现阶段实现。

## Alternatives

### 方案 B：实时数据同步

- **优点**：数据实时一致
- **缺点**：复杂、性能影响、数据安全风险、违背独立部署初衷

### 方案 C：完全互通

- **优点**：体验统一
- **缺点**：不是真正的独立部署，安全合规风险

## Consequences

### 正面

- 数据安全隔离，合规
- 独立部署真正独立，子公司自治
- 实现简单（只需元数据注册）

### 负面

- 独立部署的子公司无法参与集团跨租户流程
- 集团无法直接查看独立部署子公司的业务数据

### 缓解措施

- 流程中心预留 BridgeNode 接口
- 业务可见授权机制可用于跨部署的数据访问（通过API）
