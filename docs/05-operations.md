|---------|--------|

| 审计概览 | 跨租户访问次数、异常操作数 |

### 5.2 计量管理

#### 5.2.1 功能概述（可选模块）

按租户计量资源使用量，为内部结算或对外计费提供数据支持。通过功能开关控制是否启用。

#### 5.2.2 计量维度

| 维度 | 计量单位 | 说明 |
|------|---------|------|
| 用户数 | 人 | 活跃用户数/总用户数 |
| 存储量 | GB | 文件存储使用量 |
| API调用 | 次 | 接口调用次数 |
| 流程实例 | 个 | 流程发起数量 |
| 消息发送 | 条 | 各渠道消息发送量 |
| 文件上传 | 个 | 文件上传数量 |

#### 5.2.3 数据模型

```
opr_metering_record（计量记录表）
├── id
├── tenant_id            租户ID
├── metering_type        计量类型
├── metering_value       计量值
├── period               计量周期（YYYY-MM-DD / YYYY-MM）
├── created_at
└── extra

opr_metering_rule（计量规则表）
├── id
├── rule_name            规则名称
├── metering_type        计量类型
├── billing_mode         计费模式（COUNT/SIZE/TIME）
├── unit_price           单价（内部结算用）
├── free_quota           免费额度
└── status
```

### 5.3 监控告警

#### 5.3.1 功能概述

提供系统级监控和告警能力，包括服务健康监控、性能指标监控、阈值告警。

#### 5.3.2 监控维度

| 维度 | 监控项 |
|------|--------|
| 服务健康 | 各模块运行状态、数据库连接状态 |
| 性能指标 | 响应时间、吞吐量、错误率 |
| 资源指标 | CPU、内存、磁盘、数据库连接池 |
| 业务指标 | 活跃租户数、流程处理时长、消息发送延迟 |
| 安全指标 | 登录失败次数、异常操作次数、跨租户访问频次 |

#### 5.3.3 告警机制

```
告警规则配置：
├── 指标项（如：错误率）
├── 条件（如：> 5%）
├── 持续时间（如：持续5分钟）
├── 告警级别（INFO/WARN/CRITICAL）
└── 通知方式（站内信/邮件/短信/Webhook）

告警流程：
指标采集 → 阈值判断 → 触发告警 → 通知发送 → 告警确认 → 告警恢复
```

### 5.4 资源治理

#### 5.4.1 功能概述

提供配额管理、资源清理、存储优化等治理能力。

#### 5.4.2 核心功能

- **配额管理**：配置/调整各租户配额，查看配额使用
- **配额预警**：用量达阈值（80%/90%）自动通知
- **过期数据清理**：过期文件、过期审计日志、过期会话清理
- **存储优化**：重复文件检测（MD5去重）、冷热数据分离
