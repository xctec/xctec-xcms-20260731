# Implementation Roadmap

## 9. 实施路线

### 9.1 分期规划

#### Phase 1：核心基础层（MVP）

**目标**：搭建 XCMS 骨架，实现租户、组织、身份、权限基础能力。

| 模块 | 功能范围 |
|------|---------|
| shared-kernel | 租户上下文、数据源路由、基础实体 |
| tenant-management | 级联租户创建/管理/配额/生命周期 |
| organization | 部门树/岗位/人员分配 |
| identity | 用户管理/本地登录/会话管理 |
| authorization | RBAC/行级数据权限/列级权限 |
| portal | 基础门户框架/管理面/业务面路由 |

**交付物**：
- 可运行的单体应用
- 租户/组织/用户/权限完整管理
- 管理面 + 业务面基础界面

#### Phase 2：流程中心 + 共享服务

**目标**：补齐流程中心和共享业务能力。

| 模块 | 功能范围 |
|------|---------|
| workflow | Flowable集成/拖拽设计器/审批流/跨租户流程 |
| message | 站内信/通知/消息模板/多渠道 |
| configuration | 系统参数/功能开关/字典/编码规则 |
| file-storage | 文件上传下载/预览/分享/配额 |
| audit | 操作审计/登录审计/跨租户审计 |

**交付物**：
- 完整的流程中心（含跨租户）
- 消息/配置/文件/审计服务
- 业务面工作台

#### Phase 3：运营管理 + 完善优化

**目标**：补齐运营管理能力，完善非功能性需求。

| 模块 | 功能范围 |
|------|---------|
| operation | 运营看板/监控告警/资源治理 |
| task-scheduling | 定时任务/异步任务/执行监控 |
| SSO | OAuth2/OIDC单点登录 |
| 业务可见授权 | 授权流程/令牌管理/审计 |
| 计量管理 | 计量规则/计量报表（可选） |

**交付物**：
- 运营看板
- 任务调度中心
- SSO登录
- 完整的安全审计

#### Phase 4：独立部署 + 扩展预留

**目标**：支持子公司独立部署，预留扩展能力。

| 功能 | 说明 |
|------|------|
| 独立部署模式 | 配置切换 shared/dedicated 模式 |
| 元数据注册 | 独立部署租户与集团管理面对接 |
| 流程桥接预留 | BridgeNode 接口定义 |
| 开发者门户 | API文档/应用管理（预留） |
| 第三方登录 | 钉钉/企微/飞书对接 |

**交付物**：
- 独立部署能力
- 扩展预留接口

### 9.2 里程碑

```
Phase 1 ──────────── Phase 2 ──────────── Phase 3 ──────────── Phase 4
核心基础层            流程+共享服务        运营+完善            独立部署
   │                    │                    │                    │
   │                    │                    │                    │
   ▼                    ▼                    ▼                    ▼
┌──────┐           ┌──────┐           ┌──────┐           ┌──────┐
│ M1   │           │ M2   │           │ M3   │           │ M4   │
│ 可用 │           │ 可用 │           │ 可用 │           │ 可用 │
│骨架  │           │流程+ │           │运营+ │           │独立  │
│      │           │服务  │           │SSO   │           │部署  │
└──────┘           └──────┘           └──────┘           └──────┘
```

| 里程碑 | 内容 | 验收标准 |
|--------|------|---------|
| M1 | 核心基础层可用 | 多租户创建/用户/权限完整可操作 |
| M2 | 流程+共享服务可用 | 流程发起/审批/跨租户流转完整 |
| M3 | 运营+SSO+审计可用 | 看板/单点登录/审计完整 |
| M4 | 独立部署可用 | 子公司可独立部署并注册到集团 |
